# 🎓 AI Exam Preparation Assistant

## 📌 Project Description

AI Exam Preparation Assistant is a beginner-level AI application designed to help college students prepare for exams.

The application uses an LLM API to generate simple, clear, and exam-oriented explanations for user-provided topics.

## 🚀 Features

- Enter any exam topic
- Generate AI-powered explanations
- Simple and easy-to-understand content
- Important exam points
- Examples where applicable
- Input validation
- API error handling
- Simple Streamlit user interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Groq API
- LLM
- python-dotenv
